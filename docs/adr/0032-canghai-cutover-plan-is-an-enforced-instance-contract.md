# CangHai Cutover Plan is an enforced instance contract

CangHai's Instance Cutover Plan requires remote pull and base checks before
publication, successful push before `sync`, removal of legacy `30_RAG` retrieval,
disabling `active-memory`, deployment of target-Generation `USER.md` and
`MEMORY.md`, and preservation of the independent Public Author Corpus. Runtime's
Activation Barrier executes or verifies these declared transitions atomically;
they are not manual cleanup after activation and are not defaults imposed on
unrelated Private Instances.
