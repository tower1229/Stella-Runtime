# Host projections derive from structured Generation entries

Each Generation contains host-neutral structured Projection Entries, and the
Runtime's host adapter deterministically renders matching host retrieval
artifacts such as OpenClaw Markdown. `USER.md` and `MEMORY.md` are optional
Bootstrap Projections generated by the Runtime but deployed only by Instance
Integration; keeping both outputs downstream of the same structured entries
preserves strict validation without making a host workspace or a second format
an authority source.

An Instance Cutover Plan may make these projections mandatory for a particular
migration. CangHai's Stella migration deploys both as read-only files marked with
the target Generation inside the same successful Activation Barrier.
