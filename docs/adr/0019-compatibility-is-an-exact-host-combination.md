# Compatibility is an exact host combination

Before 0.2.0 deployment, the actual host determines the exact OpenClaw and Node
combination that must pass Generation Consumption, Confirmation Gateway, package,
restart, and failure-path smoke. A Compatibility Matrix Row binds that exact
combination and release channel; package engine ranges remain installation
constraints but do not authorize `enforce`, and neither a second local install
nor a greater version implies support.
