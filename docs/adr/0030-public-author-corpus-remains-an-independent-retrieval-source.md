# Public Author Corpus remains an independent retrieval source

The Public Author Corpus stays canonical in the consumer repository and remains
an independently configured retrieval source. It is not copied into private
Authority, wrapped as private Evidence, included in Generation identity, or
indexed through the Generation Projection. Runtime preserves its declared host
path across `sync`, while CangHai's Public Corpus Adapter and acceptance pack
verify functional continuity and keep author works epistemically separate from
private user Authority.
