# Release requires exact-host Generation Consumption acceptance

Runtime 0.2.0 is not consumption-complete until the exact supported OpenClaw and
Node combination proves one approved Authority Candidate becomes a local
Authority commit, deterministic Generation and Markdown Projection, verified
OpenClaw index, Activation Receipt and Active Pointer, and is actually bound by
the next Eligible Run.

Acceptance also injects configuration update, index, retrieval sentinel, and
process-interruption failures. Each case must either keep new Runs behind the
Maintenance Gate or restore and verify the prior configuration, index, and
Generation, with an accurate Publication Status Reply. Production rollout reads
the actual host versions, performs migration and self-check in `off`, completes
first sync and the real path in `observe`, and enables `enforce` only after every
compatibility and Receipt gate passes.

CangHai acceptance additionally proves its Authority commit was pushed before
sync, legacy `30_RAG` retrieval and `active-memory` are disabled inside the
Barrier, both Generation-marked Bootstrap Projections are deployed, the
independent Public Author Corpus remains searchable, and legacy private-path
hits are zero before `enforce`.
